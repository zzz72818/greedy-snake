# Greedy Snake 單檔離線版設計

## 目標

產出 `GreedySnake.html`。使用者不需安裝任何套件，直接以現代瀏覽器雙擊開啟即可離線遊玩。

## 封裝方式

- HTML、CSS 與 JavaScript 全部內嵌在單一檔案。
- 不引用 CDN、字型、圖片、音效或任何網路資源。
- 保留鍵盤方向鍵、WASD、手機觸控方向鍵、暫停、重新開始與最高分。
- 最高分僅儲存在該瀏覽器的 `localStorage`，不需要帳號或伺服器。

## 維護方式

現有 Next.js 專案仍是主要可維護原始碼；離線檔案是獨立交付物，不改變線上版本。單檔內部以 `CONFIG`、遊戲引擎、畫面更新、輸入控制四個區塊分隔，方便日後修改。

## 驗收條件

1. 檔案只有一個 `.html`，且不存在外部資源網址。
2. 以 `file://` 方式載入時能顯示完整遊戲。
3. 開始、移動、吃食物、碰撞、暫停與重玩邏輯可執行。
4. 關閉網路後仍可正常使用。

## 非本次範圍

- 帳號登入、雲端最高分與多人連線。
- 將單檔版重新發布至線上網站。
- 內嵌大型圖片或音效素材。
